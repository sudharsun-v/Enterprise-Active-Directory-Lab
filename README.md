This repository documents my hands-on Enterprise Active Directory lab, built to develop and demonstrate practical Identity and Access Management (IAM) skills.

- Build an enterprise Active Directory environment.
- Demonstrate identity administration and security best practices.
- Automate administrative tasks using PowerShell.
- Document the implementation with screenshots and diagrams.
